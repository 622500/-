FAULT-001 SEV-1 · P0

状态机死锁与底盘控制权抢占

State-machine deadlock & chassis authority contention

现象 · Symptom

手动摇杆与自主导航在并发工况下同时写入底盘指令通道，两路控制源争夺执行权；机器人于原地高频震荡，位姿收敛失败，遥测曲线呈现持续自激。

根因 · Root Cause

控制层缺少指令仲裁与互斥语义：手动接管未被定义为硬中断，运动状态机在阻塞工况下自锁；死区阈值缺失，零速附近的抖动被闭环持续放大。

手术 · Surgical Fix

引入基于优先级的指令仲裁器（Priority-based Arbitrator），确立「手动接管 > 自动导航」的硬中断机制并设定死区阈值；控制权切换原子化，任一时刻仅允许一个控制源持有底盘写权限。

FAULT-002 SEV-1 · P0

同源策略与后台帧率节流

Same-origin policy & background rAF throttling

现象 · Symptom

多页面架构下，切换至 3D 页签后浏览器将该文档判定为不可见，主物理引擎的 requestAnimationFrame 被挂起，帧率归零；遥测数据冻结，状态机与视图失去同步。

根因 · Root Cause

浏览器对不可见文档实施后台帧率节流（Background Throttling）；3D 视图与物理引擎分属不同文档上下文，无法共享同一渲染时钟，主循环被降级为 0 Hz。

手术 · Surgical Fix

果断放弃多页交互，实施 iframe 沙盒隔离重构：3D 客户端运行于独立文档，DOM / CSS / JS 作用域完全隔离；通过 window.parent.state 同源直连绕过跨域限制，省去 BroadcastChannel 与状态拷贝，实现零延迟状态同步，且 iframe 始终处于同一可见视口，主循环不再被节流。

FAULT-003 SEV-0 · BLOCKER

单体合并灾难与 DOM 树坍塌

Monolith merge failure & DOM tree collapse

现象 · Symptom

试图以正则表达式将 3D 渲染逻辑强行并入主文件（约 5000 行），导致 DOM 结构错位、标签闭合失配；2D 地图与物理循环全线瘫痪，页面白屏。

根因 · Root Cause

全量重写使修改边界失控：以文本替换处理结构化代码，缺少语法级校验与回归基线；单文件高耦合令故障半径覆盖整个运行时。

手术 · Surgical Fix

调用本地完整备份执行时空回溯（Rollback）；确立「微创手术（Surgical Edit）」原则——禁止 AI 全量重写，每次变更限定最小可验证边界，改动前必须保留可回滚基线。

FAULT-004 SEV-2 · P1

离散算法与连续物理的坐标系错位

Discrete planner vs. continuous kinematics misalignment

现象 · Symptom

A* 在栅格上的离散路径与差速运动学的连续轨迹发生冲突，路径拐点无法被底盘精确复现；小车沿障碍边缘切入障碍内部，出现「穿墙」。

根因 · Root Cause

规划层与执行层的自由度假设不一致：栅格路径隐含零半径转向能力，而差速底盘受非完整约束与最小转弯半径限制；执行层缺少路径与碰撞体的一致性校验。

手术 · Surgical Fix

建立「执行层物理优先，演示层算法映射」的妥协原则：重写兜底逻辑，以「L 型狗腿绕行」替代直线冲锋；在拐点插入可执行段并做碰撞体一致性校验，确保规划输出始终落在运动学可行域内。

FAULT-005 SEV-3 · P2

原生依赖缺失与平台兼容性坍塌

Missing native artifact & platform compatibility collapse

现象 · Symptom

在 Android / Termux（ARM64）环境部署 dsh-synapse 会话地图插件时，require-builtin.node 缺少对应架构的原生编译产物，插件加载失败；移动端内存溢出进一步导致进程中断。

根因 · Root Cause

预编译原生模块的架构覆盖不足，ARM64 无可用二进制；移动端运行时对 Node.js / pnpm 依赖链的支持边界，未被纳入最初的设计假设。

手术 · Surgical Fix

执行止损决策（Stop-loss）：冻结移动端路径，转向标准桌面环境重建 Node.js、pnpm 与 DSH 插件的依赖链；并将该失败链路完整复盘，转化为对微内核插件机制的系统性验证结论。

1. 遥操作控制台 (Teleoperation)

  • 虚拟摇杆：Y轴控制前进/后退，X轴控制转向（非完整约束差速模型）。
  • 快捷动作：急停（最高优先级锁死）、保持（原地清零）、返航（规划返航至原点）、低速（限制最高速度0.2m/s）。

2. 全局与三维视图 (Global View & 3D)

  • 2D全局视图：点击地图下发目标点，自动触发 A* 全局规划。蓝色扇形为激光雷达，紫色梯形为相机视野，动态橙色方块用于测试局部避障。
  • 3D视图：点击3D按钮滑出，利用iframe沙盒隔离。2D物理坐标(x, y, yaw)实时映射至3D世界的(x, z, -yaw)，实现零延迟同步。

3. 算法演示对比 (ALGO DEMO)

不仅可视化 A* 的寻路过程（Open List波光扩散与Closed List锁定），还支持 A* 与 Dijkstra 的双算法效率对比。通过对比节点的扩展数量、路径长度和毫秒级求解耗时，量化展示启发式函数带来的搜索剪枝收益。

4. 科研遥测面板 (Research Telemetry)

  • PID TUNING：在线调整 Kp/Ki/Kd，观察速度响应的超调与阻尼。
  • SENSOR FILTER：调整 noiseLevel σ 与 alpha α，对比带噪测量值（黄线）与互补滤波估计值（绿线）的误差收敛。
